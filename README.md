# FILESHELL

A lightweight terminal-based file explorer written entirely in Windows Batch.

## Features

- Browse folders
- Open files
- Create files
- Navigate to custom paths
- Go back through folders
- Display file information
- Aligned file listing
- Launch FILESHELL with the `fsh` command
- Simple installer that adds FILESHELL to your User PATH

## Requirements

- Windows 10 or Windows 11

## Installation

### Option 1 — Clone with Git

```cmd
git clone https://github.com/Rashdan171/Fileshell.git
cd Fileshell
Install.bat
```

After installation, **restart your terminal**.

You can then launch FILESHELL from anywhere with:

```cmd
fsh
```

### Option 2 — Download manually

Download or extract the repository, open the FILESHELL folder, and run:

```cmd
Install.bat
```

Then restart your terminal and run:

```cmd
fsh
```

## Usage

You can also run `Fileshell.bat` directly without installing it.

Once FILESHELL is running:

- Enter a number to open a file or folder
- `I` — Create a new file
- `G` — Go to a custom folder path
- `B` — Go back one folder
- `X` — Exit FILESHELL
